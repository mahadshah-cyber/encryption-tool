# Encryption Tool

JavaFX desktop application for encrypting and decrypting files using AES-256 and RSA-2048.

## Features
- AES-256 encryption/decryption (GCM mode)
- RSA-2048 encryption/decryption
- Key generation for both algorithms
- Dark-themed JavaFX GUI

## Requirements
- Java 17+
- Maven 3.8+

## Build & Run
```bash
mvn clean compile exec:java -Dexec.mainClass="com.encryptool.Main"
```
